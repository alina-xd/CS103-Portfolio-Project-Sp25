# CS103-Portfolio-Project-Sp25
- **Course**: CSCI103
- **Semester**: Spring 2025

A minimalist turn-based strategy game inspired by _The Battle of Polytopia_, redesigned to run with command line in C++.

## How to Build/Run

- To compile, run `g++ -g asset.cpp board.cpp building.cpp game.cpp player.cpp tile.cpp unit.cpp main.cpp -o main`
- To run the program, run `./main`
